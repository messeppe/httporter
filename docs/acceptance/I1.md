## Findings during acceptance

- **Bunny Storage speaks HTTP/1.1 only.** A TLS handshake offering `h2,http/1.1` to `sg.storage.bunnycdn.com` and `storage.bunnycdn.com` gets `ALPN protocol: http/1.1`. The status bar's "HTTP/1.1" is therefore correct; the mockup's "HTTP/2" was an assumption. HTTPorter negotiates HTTP/2 automatically where a server offers it (expected for S3 services in I2). For Bunny, parallel keep-alive connections remain the speed lever (spec §5.2).
- **Connection pill showed 303 ms right after start**: that is the first listing, which includes the TCP + TLS handshake. The pill already updates with each new listing's latency, so after the first folder it shows the kept-alive figure (~21 ms measured earlier). No change needed.
