## Bugs found and fixed

- **DirWatcher could miss the first change** (platform): `start` returned before the first read was posted.
  It now waits for it.
- **A Bunny move kept its emptied folder and reported a failure** (transfer, found live): Bunny's listing
  lags behind its deletes, so the old folder still listed the files the move had just deleted. Those
  files no longer count; any other file still keeps the folder.
